Chat — paste the bounty details, watch the agent work

Paste the program details and press Start. The agent streams every stage, each finding as it lands, and the final report. You can type a mid-run instruction at any time and it is applied at the next stage boundary — no restart needed. Nothing is tested until you press Start, and it is a dry run unless you tick live.

One input — a program document in, a submission bundle out

Drop in one file of program details (a PDF brief, a pasted policy, an exported HTML page) and the system does the rest: it reads the document, extracts the scope, plans the testing like a hunter would, runs it through the authorization gate, verifies what it finds, amplifies the impact and writes a report that is ready to submit. Nothing is tested until you press Run, and it is a dry run unless you tick live.
A scanned PDF with no text layer cannot be read — the tool will say so and ask you to paste the text instead.

Guided run — URL to submission-ready report
